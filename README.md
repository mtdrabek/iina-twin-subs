# IINA Beautiful Subs

IINA plugin that makes the top (secondary) subtitles look like the bottom (primary) ones.

mpv strips ASS styling from secondary subtitles by default. The plugin mirrors `sub-ass-override`
onto `secondary-sub-ass-override` and sets `secondary-sub-pos` (preference `top_pos`, default 8).

## Install
Zip `Info.json` and `index.js` into `beautiful-subs.iinaplgz`, then in IINA: Settings → Plugins → Install Local Package…
